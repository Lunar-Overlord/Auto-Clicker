Este é um auto-clicker com muitas funções que a maioria dos auto-clicker normais não tem.
Incluindo auto key clicker (Click de teclas).
Mais de um click ao mesmo tempo (no modo avançado).
E também uma opção de gravar/reproduzir (famoso macro).


Link para download: https://github.com/Lunar-Overlord/Auto-Clicker/releases


Se você não tiver python instalado o auto clicker não funcionará, baixe aqui: https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix
